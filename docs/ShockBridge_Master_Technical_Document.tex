\begin{equation}

Raw probabilities from gradient boosting trees are notoriously uncalibrated. The V5 engine utilizes Isotonic Regression to strictly align predicted probabilities with empirical reality. 
\begin{equation}
    \min_{f} \sum_{i} (y_i - f(\hat{p}_i))^2 \quad \text{subject to } f(a) \le f(b) \text{ for all } a \le b
\end{equation}
